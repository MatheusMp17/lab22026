## 📌 Sobre o Repositório

Este repositório contém a implementação de **Tipos Abstratos de Dados (TADs)**, manipulação de memória dinâmica, arquivos e algoritmos desenvolvidos ao longo do semestre.

### 🛠️ Principais Recursos e Tópicos Aplicados
* **Tipos Abstratos de Dados (TAD):** Implementação de estruturas (ex: TAD String com suporte UTF-8).
* **Gerenciamento de Memória:** Alocação dinâmica (`malloc`, `realloc`, `free`), ponteiros e controle fino de capacidade (`cap`).
* **Codificação e Texto:** Processamento de bytes e caracteres em **UTF-8**.
